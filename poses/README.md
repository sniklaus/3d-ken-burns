The contents of this folder are vibe coded with `compute.py` borrowing code from [this](https://github.com/Schmiddo/reconstruct_ken_burns) repository.

* `compute.py`: extracts the per-frame poses from the save game files
* `pointcloud.py` computes a per-scene point cloud using the extracted poses
* `flythrough.py` generates a flythrough video of a scene given its point cloud
